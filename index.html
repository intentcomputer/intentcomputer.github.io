Intent Computer Mini

A tiny computer that carries your intent.

Intent Computer Mini is a pocket-sized intent computer that sits beside the hardware you already use. It pairs over Bluetooth and appears as a normal keyboard and mouse to anything it can control.

Nothing needs to be installed on the controlled computer or device. Speak a request, review the transcript and the proposed commands on the Mini, then press Execute.

Intent Computer Mini can type text, enter terminal commands, use keyboard shortcuts, move through menus, and launch applications. It handles the voice input and keeps your provider credentials; the other machine receives ordinary keyboard and mouse actions.

Built Over Time

This has been building for a while.

Intent Computer grew out of earlier projects that tested web-based operating environments, Android assistants, Bluetooth command devices, and agent systems.

  1. Agent1c

    An experimental web-based operating environment.

  2. Hitomi

    A floating Android assistant with browser and terminal access.

  3. Dissenter

    The original Android and standalone voice-command devices behind Intent Computer Mini.

  4. Myriad and DeBio

    Earlier agent systems that shaped the reviewed-action workflow.

The first pieces already work. Intent Computer Mini can turn spoken requests into reviewed Bluetooth commands from a pocket-sized device. Current hardware experiments explore what happens when the computer itself is built around that interaction.
